Yes! A chest-style pickup is a simpler and more controlled approach. Instead of worrying about collider triggers not working correctly on individual arrows, you can make it so the player enters a chest's trigger zone, and arrows are automatically added.

🔹 How to Set Up a Chest That Gives Arrows
Create a Chest Object

In Unity, create a Cube or Chest prefab (GameObject → 3D Object → Cube).

Add a Collider component (Box Collider or Sphere Collider).

Set "Is Trigger" to true (so it only detects entry, not physical collisions).

Assign a Script to the Chest

Attach the following ChestPickup script:

✅ ChestPickup.cs
csharp
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class ChestPickup : MonoBehaviour
{
    public int arrowAmount = 5; // Arrows given when opened

    void OnTriggerEnter(Collider other)
    {
        if (other.CompareTag("Player")) // Ensure player is detected
        {
            Inventory playerInventory = other.GetComponent<Inventory>(); // Get Inventory component
            
            if (playerInventory != null)
            {
                playerInventory.CollectArrow(arrowAmount); // Add arrows
                Debug.Log($"Chest opened! {arrowAmount} arrows added.");
                Destroy(gameObject); // Remove the chest after pickup
            }
            else
            {
                Debug.LogError("Player does not have an Inventory component!");
            }
        }
    }
}
✔ Now, when the player enters the chest area, they get arrows! ✔ This avoids the javelin’s collider issues and makes pickups smooth. ✔ You can change Destroy(gameObject); to keep the chest visible after pickup.
